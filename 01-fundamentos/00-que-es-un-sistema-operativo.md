# 00 - ¿Qué es un sistema operativo?

## Objetivo

Entender qué es el sistema operativo (SO) y por qué lo necesitás para programar.

## Idea principal

El **sistema operativo** es el programa principal de tu computadora. Se encarga de que todo funcione: administra la memoria, los archivos, el teclado, la pantalla, la red y los programas que abrís.

Ejemplos: **Windows**, **Linux** (Ubuntu, Debian) y **macOS**.

## Analogía

Pensá en el sistema operativo como el **encargado de un edificio**:
- Reparte las llaves (permisos).
- Asigna habitaciones (memoria).
- Mantiene el orden (archivos y programas).
- Se asegura de que los vecinos no se molesten entre sí.

Tus programas (incluido Python) no hablan directamente con el hardware: le piden cosas al sistema operativo.

## ¿Por qué importa en este curso?

- Vas a usar **Windows con WSL**: una forma de tener Linux dentro de Windows.
- Los comandos de terminal (PowerShell y Bash) son formas de pedirle cosas al sistema operativo.
- Muchas herramientas de IA (Python, bases de datos, servidores) corren mejor en Linux.

## Términos que vas a escuchar

| Término | Qué es |
|---|---|
| **Kernel** | El núcleo del SO; habla directamente con el hardware. |
| **Terminal** | Ventana donde escribís comandos. |
| **Shell** | El programa que interpreta esos comandos (PowerShell, Bash). |
| **Archivo** | Un conjunto de datos guardado con un nombre. |
| **Directorio (carpeta)** | Un lugar que agrupa archivos. |

## Recapitulación

- El SO administra los recursos de la computadora.
- Tus programas le piden cosas al SO, no al hardware.
- La terminal es una forma de comunicarte con el SO.
