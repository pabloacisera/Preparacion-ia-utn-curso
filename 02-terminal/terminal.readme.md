# Terminal

Una terminal es una interfaz gráfica o ventana (un cascarón) cuya única finalidad es capturar lo que escribimos.

Toda terminal poseen un shell, que es un motor de interprete de comandos que es el que traduce lo escrito a un lenguaje que el sistema operativo entiende. También es una sintaxis que nos permite crear **scripts** (bloques de instrucciones en archivos) para automatizar tareas.

Para el caso de windows posee **Powershell**, en el de linux/unix utiliza **Bash** (*Bourne Again Shell*).

> Como vamos a usar un subsistema de windows, vamos a trabajar con ambos, pero nos enfocaremos en bash.
