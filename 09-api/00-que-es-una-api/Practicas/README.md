# Prácticas - ¿Qué es una API?

## Objetivo

Reforzar el concepto con observación práctica, sin escribir código complejo.

## Práctica 1: Identificar APIs en tu día a día

Observa y responde mentalmente (o anota):

1. Abre una app de clima. ¿De dónde obtiene los datos?
2. Usa "Iniciar sesión con Google/Facebook". ¿Qué está pasando ahí?
3. ¿Has visto alguna app que use mapas? ¿Quién provee esos mapas?

**Reflexión:** En todos estos casos hay una comunicación entre apps mediante una API.

## Práctica 2: Piensa como camarero

Usando la analogía del restaurante:

- **Cliente**: ¿Quién pide?
- **Camarero (API)**: ¿Qué función cumple?
- **Cocina (Servidor)**: ¿Qué hace con la petición?
- **Respuesta**: ¿Qué nos devuelven?

Escribe tus respuestas con tus propias palabras.

## Práctica 3: API vs Sitio Web

Investiga mentalmente la diferencia:

- **Sitio web**: Muestra una página visual para humanos.
- **API**: Devuelve datos para que otras aplicaciones los usen.

**Pregunta para pensar:** ¿Qué formato podrían devolver esos datos? (Lo veremos en la siguiente sección)
