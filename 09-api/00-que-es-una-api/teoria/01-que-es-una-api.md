# ¿Qué es una API?

## Objetivo

Entender qué es una API, su contexto, dónde y cuándo se usa, con un lenguaje claro para alguien sin base de programación.

## ¿Qué significa API?

**API** significa *Application Programming Interface* (Interfaz de Programación de Aplicaciones). 

En pocas palabras: **una API es un contrato que permite que dos aplicaciones se comuniquen entre sí de forma ordenada**.

## Analogía: El restaurante

Imagina que vas a un restaurante:

1. **Tú (cliente)**: Quieres pedir una pizza. No entras a la cocina a cocinarla tú mismo.
2. **El camarero (API)**: Toma tu pedido, lo lleva a la cocina con las indicaciones correctas y te trae la respuesta (la pizza).
3. **La cocina (servidor/aplicación)**: Prepara lo que pediste siguiendo las reglas.

**La API es como ese camarero**: te permite pedir lo que necesitas sin tener que conocer todos los detalles de cómo funciona la cocina.

## ¿Dónde y cuándo se usa?

Las APIs están por todas partes:

- **Apps móviles**: Cuando abres una app del clima, esta pide los datos a una API del tiempo.
- **Sitios web**: Para mostrar precios de productos, inicios de sesión, etc.
- **Inteligencia Artificial**: Para hablar con un modelo de IA (ChatGPT, Groq, Gemini) usas su API.
- **Pagos online**: Las pasarelas de pago exponen APIs para procesar compras de forma segura.

## ¿Por qué son importantes?

- **Orden**: Definen cómo pedir y qué esperar a cambio.
- **Seguridad**: No das acceso directo a toda la base de datos, solo lo necesario.
- **Reutilización**: Un mismo servicio puede ser usado por web, app móvil, etc.
- **Escalabilidad**: Permiten conectar sistemas sin reescribir todo.

## ¿Qué NO es una API?

- **No es una interfaz gráfica**: Aunque hay interfaces gráficas que usan APIs, la API en sí es la forma de comunicación.
- **No es un sitio web completo**: Un sitio web muestra páginas; una API suele devolver datos (como JSON).

## ¿Qué aprenderemos después?

Ahora que entendemos el concepto, veremos **cómo es el flujo entre cliente y servidor** para entender qué va y qué viene en una petición.
