# 09-API: APIs para principiantes

## Objetivo

Aprender qué es una API, cómo funciona el flujo petición-respuesta, los tipos de peticiones HTTP, el versionado, su uso en IA y practicar con `curl`.

## Prerrequisitos

- Haber completado `02-terminal/` y `04-bash/` (conocimientos básicos de terminal y línea de comandos).
- No se asume conocimiento previo de programación.
