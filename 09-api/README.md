## ¿Por qué es importante para LLM, agentes y RAG?

- **LLMs**: se consumen por API (Chat Completions).
- **Agentes**: usan APIs como herramientas para actuar.
- **RAG**: usa APIs de embeddings y bases vectoriales.
- **Automatización**: podés integrar cualquier servicio con un script.
