# Prácticas - Introducción a SQL

## Objetivo

Familiarizarse con los conceptos sin escribir SQL aún.

## Práctica 1: Identificar tablas

Piensa en una tienda online. ¿Qué tipo de información necesitarías guardar?

Anota posibles tablas:
- ¿Qué tabla guardarían los **clientes**?
- ¿Qué tabla guardarían los **productos**?
- ¿Qué tabla guardarían las **compras/pedidos**?

## Práctica 2: Filas y columnas

Para una tabla `clientes`, ¿qué columnas tendría sentido?

Ejemplo mental:
- `id`
- `nombre`
- `email`
- `telefono`

¿Falta alguna? ¿Por qué?

## Práctica 3: Pensar en relaciones

Si un cliente hace un pedido, ¿cómo lo relacionamos?

**Pregunta:** ¿Deberíamos duplicar todos los datos del cliente en cada pedido, o guardar una referencia?
