# ¿Qué es SQL?

## Objetivo

Entender qué es SQL, qué es una base de datos y por qué es fundamental para organizar información.

## ¿Qué es una base de datos?

Una **base de datos** es un lugar organizado para guardar, buscar, actualizar y eliminar información de forma estructurada.

Piensa en una hoja de cálculo gigante, pero mucho más potente, con reglas para mantener los datos correctos y relaciones entre ellos.

## ¿Qué es SQL?

**SQL** significa *Structured Query Language* (Lenguaje de Consulta Estructurado). 

Es el lenguaje que usamos para **hablar** con bases de datos relacionales. Con SQL podemos:

- **Crear** tablas y bases de datos
- **Guardar** información (`INSERT`)
- **Buscar** información (`SELECT`)
- **Modificar** información (`UPDATE`)
- **Eliminar** información (`DELETE`)

## ¿Base de datos vs SQL?

- **Base de datos**: Es el almacén donde guardamos la información.
- **SQL**: Es el idioma que usamos para pedirle cosas a ese almacén.

**Analogía:** Si la base de datos fuera una biblioteca, SQL sería el formulario/idioma que usas para pedir un libro al bibliotecario.

## ¿Qué es una base de datos relacional?

Una **base de datos relacional** guarda la información en **tablas** que se relacionan entre sí usando claves.

- **Tabla**: Como una hoja con un tipo de información (clientes, productos)
- **Fila (registro)**: Cada entrada individual
- **Columna (campo)**: Cada atributo de esa entrada

**Ventajas:**
- **Sin duplicados innecesarios**: Los datos se organizan eficientemente
- **Relaciones claras**: Podemos unir información de diferentes tablas
- **Consistencia**: Se mantienen reglas para evitar datos incorrectos
- **Consultas potentes**: Podemos filtrar, ordenar y combinar datos

## ¿Cuándo usamos SQL?

- **Aplicaciones web**: Usuarios, pedidos, productos
- **Sistemas empresariales**: Inventarios, facturación
- **Análisis de datos**: Reportes y estadísticas
- **Agentes e IA**: Para consultar información estructurada
- **RAG híbrido**: Combinar búsqueda semántica (vectorial) con filtros SQL
