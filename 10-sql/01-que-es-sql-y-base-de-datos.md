# 01 - ¿Qué es SQL y qué es una base de datos?

## Objetivo

Comprender qué son SQL y las bases de datos, y cuándo usarlos.

## ¿Qué es una base de datos?

Una **base de datos** es un lugar organizado donde se guarda información de forma estructurada para poder buscarla, actualizarla, eliminarla y agregarla fácilmente.

Piensa en ella como un archivo digital gigante, pero mucho más ordenado que una carpeta con archivos sueltos.

## ¿Qué es SQL?

**SQL** (*Structured Query Language* - Lenguaje de Consulta Estructurado) es el lenguaje que usamos para comunicarnos con las **bases de datos relacionales**.

Con SQL le decimos a la base de datos: *"Muéstrame esto", "Guarda esto", "Cámbialo", "Bórralo"* usando comandos claros.

## ¿Diferencia entre base de datos y SQL?

- **Base de datos** = El lugar donde se guarda la información
- **SQL** = El idioma que usamos para hablar con ese lugar

**Analogía:** Si la base de datos fuera una biblioteca, SQL sería el lenguaje que usas para pedirle libros al bibliotecario.

## ¿Qué es una base de datos relacional?

Una **base de datos relacional** organiza la información en **tablas**. Estas tablas pueden **relacionarse** entre sí para evitar repetir información.

**Ventajas:**
- **Ordenado**: Todo tiene su lugar
- **Sin duplicados**: Evita guardar lo mismo muchas veces
- **Relaciones**: Une información de distintas tablas
- **Confiable**: Mantiene la información coherente
- **Potente**: Permite hacer consultas complejas

## ¿Dónde se usan?

- **Sitios web**: Usuarios, productos, carrito de compras
- **Aplicaciones**: Pedidos, clientes, facturación
- **Sistemas empresariales**: Inventarios, reportes
- **IA y Agentes**: Consultar información estructurada de forma precisa
- **RAG**: En combinación con bases de datos vectoriales
