## ¿Por qué es importante para LLM, agentes and RAG?

- **Text-to-SQL**: agentes que consultan bases de datos con lenguaje natural.
- **Datos reales**: respuestas basadas en información actualizada.
- **Híbrido**: SQL + RAG para sistemas empresariales.
- **Herramientas**: muchos agentes usan SQL como herramienta para actuar.
