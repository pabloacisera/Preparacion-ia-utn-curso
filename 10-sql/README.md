# 10-SQL

## ¿Qué aprenderás?

Aprenderás los fundamentos de SQL, bases de datos relacionales, cómo crear, consultar, modificar y eliminar datos. También verás migraciones, `INNER JOIN`, y la relación entre SQL, bases de datos relacionales y bases de datos vectoriales para IA/RAG.
