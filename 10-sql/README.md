# 10-SQL: Bases de datos relacionales para IA y RAG

## Objetivo

Aprender SQL desde cero: qué es una base de datos relacional, tablas, relaciones, CRUD, consultas condicionales, `INNER JOIN`, migraciones, y cómo se relaciona con IA/RAG (diferencia con bases vectoriales).

## Prerrequisitos

- Haber completado `02-terminal/`, `04-bash/`, `06-git/`, `08-python/` (recomendado tener nociones básicas).
- No se asume experiencia con bases de datos.
