# Propuesta Resumida para el Correo

## Nombre comercial

**Asistente IA a medida**  
*Tus documentos, tus reglas.*

## Nombre académico

**Agentes de IA con LangChain y RAG: construí tu herramienta**  
*Del prototipo no-code al agente con documentos privados, herramientas propias y despliegue.*

## En una frase

Un curso práctico para que cualquier profesional pueda crear un asistente de IA que lea sus documentos, use sus herramientas y responda con sus reglas, sin entrenar modelos y sin depender de un programador.

## El problema que resuelve

Pero las empresas y los profesionales necesitan usar IA con **documentos privados**, **herramientas propias** y **reglas claras**. Una pequeña empresa o individuo no va a entrenar un modelo desde cero; necesita un agente que lea sus PDF, planillas y contratos, y actúe con esa información.

Ese espacio, el de los agentes aplicados, hoy está vacío.

## Qué se lleva el alumno

Al terminar, el alumno tiene un agente funcional que:

- Lee y entiende sus documentos: PDF, DOCX, XLSX, imágenes con OCR.
- Responde con un contexto bien determinado, reduciendo alucinaciones.
- Usa herramientas personalizadas: archivos, bases de datos, APIs, voz.
- Se conecta a servidores MCP propios y externos.
- Se puede usar desde la terminal o como servicio con FastAPI.
- Queda documentado y versionado en GitHub como portfolio.

## A quién está dirigido

Profesionales, docentes, técnicos, administrativos, emprendedores y estudiantes avanzados que quieran usar IA en su actividad diaria. No requiere experiencia previa en IA. Python y SQL se nivelan en las primeras clases.

## Proyecto final

**Agente de conocimiento privado con herramientas propias.** Incluye:

- Ingesta de al menos 3 documentos.
- Pipeline RAG con chunking, embeddings y base vectorial.
- Agente LangChain con al menos 2 herramientas propias.
- Servidor MCP propio conectado.
- Interfaz mínima en CLI o FastAPI.
- README, `.env.example` y demo de 3 minutos.

## Contenidos principales

1. Entorno, terminal, Git y Python esencial.
2. APIs, JSON y SQL.
3. LLMs, tokens, embeddings y agentes.
4. LangChain: prompts, chains, agentes y tools.
5. RAG: documentos, chunking, bases vectoriales y evaluación.
6. Herramientas propias: PDF, DOCX, XLSX, OCR y voz.
7. MCP: servidores propios e integración con agentes.
8. Agentes no-code: specs, skills y opencode.
9. Infraestructura: FastAPI, Docker, logs y costos.
10. Proyecto final integrador.
