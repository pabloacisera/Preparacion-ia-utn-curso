# Planificación

> Carpeta **interna de trabajo**. No es material de estudio: son los documentos con los que se **diseña** y **organiza** el curso. El alumno no necesita leerla.

## Contenido

- **[ESTADO.md](./ESTADO.md):** nota de traspaso. Leer esto **primero** al retomar el trabajo (qué está hecho, qué falta y las decisiones tomadas).
- **[Ruta-del-Curso.md](./Ruta-del-Curso.md):** la "escalera" del recorrido (de una frase a una aplicación con IA), qué está hecho y qué falta, y las decisiones abiertas del programa.
- **[Schedule.md](./Schedule.md):** cronograma de preparación del curso y de los entregables.
- **[Topics.md](./Topics.md):** filosofía pedagógica, cursos de certificación de referencia y recursos para equipos de bajos recursos.

## Filosofía en una frase

- **De lo menos a lo más, paso a paso.** Primero se llama a la API "a mano"; después aparecen las librerías (LangChain), y cada pieza nueva nace de un **fallo** de la anterior que el alumno ya vio.
- **De la superficie a las tripas.** Se empieza por lo que se puede usar enseguida y, luego, se abre la caja negra: qué son los tokens, por qué alucina, cómo se recupera información.
- **Nada pesado hasta que haga falta.** Se mide el peso de cada dependencia y se justifica cada elección.

> Las decisiones de orden de los módulos (10 a 15) están en el [README principal](../../README.md). Esta carpeta guarda el **porqué** de esas decisiones.
